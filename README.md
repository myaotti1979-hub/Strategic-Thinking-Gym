# Strategic Thinking Gym

**ケースで鍛える事業戦略フレームワーク**

MBAレベルのケーススタディ1,000問で、10種の戦略フレームワークを実践的に学べるPWAアプリです。

## 概要

実際のビジネス状況を読み、4つの選択肢から最適な戦略判断を選ぶ形式。1問1問が「自分の頭で状況を分析し、構造的に判断する」体験を提供します。

- 全1,000問を完全収録（追加課金なし）
- オフラインでも学習可能（PWA対応）
- Gemini APIで追加問題の自動生成も可能
- SRS（間隔反復）で記憶定着を最適化

## 出題モード

### 📝 個別問題
フレームワークと難易度を選んで出題。未回答・誤答のみのフィルタリングも可能。

### 📋 総合ケース
1つの架空企業に対して10フレームワークを横断的に適用する一貫シナリオ。初級10社・中級10社・上級15社の計35社を収録。

### 🔄 SRS復習
間隔反復システムで、間違えた問題を最適なタイミングで再出題。

### 💬 AI壁打ち（Gemini連携）
回答後にGemini APIと対話形式で深掘り。「なぜこの選択肢が最適か」「他の選択肢ではなぜダメか」を議論。

## 主な機能

- **ダッシュボード** — FW別の正答率・進捗を一覧表示
- **問題検索** — キーワードで1,000問から検索
- **学習カレンダー** — 日別の学習記録を可視化
- **問題作成** — Gemini APIで新規問題を自動生成
- **データ管理** — 回答履歴のエクスポート/インポート/同期
- **ダーク/ライトモード** — 切替対応

## 使い方

1. GitHub Pagesまたは任意のWebサーバーでホスティング
2. ブラウザで `index.html` にアクセス
3. 「ホームに追加」でPWAとしてインストール可能
4. オフラインでも全機能が利用可能

### Gemini API連携（任意）

1. 設定画面でGemini APIキーを入力
2. 「AI壁打ち」と「問題作成」が有効化
3. 対応モデル: Gemini 2.5 Pro / Flash / Flash Lite

## 技術仕様

- **フロントエンド**: Vanilla JavaScript（フレームワーク不使用）
- **データ**: `cases.js` でグローバル変数 `CASES` として読込
- **永続化**: localStorage（回答履歴・SRS・設定）
- **同期**: Firebase Realtime Database（任意）
- **PWA**: Service Worker + Web App Manifest
