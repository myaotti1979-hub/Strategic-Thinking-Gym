# Strategic Thinking Gym

**ケースで鍛える事業戦略フレームワーク**

マーケティングフレームワーク10種×3難易度の事業戦略ケーススタディ練習アプリ（PWA）。
Gemini API連携の壁打ちモードで戦略議論を深め、AIが弱点を分析しパーソナライズされたコーチングを提供。
さらにGemini APIで新しい問題を自動生成し、品質チェック後に追加可能。

## コンテンツ

|---|---|---|---|
| 🟢 初級 | 250問 | 15社×10ステップ＝150問 | 400問 |
| 🟡 中級 | 250問 | 10社×10ステップ＝100問 | 350問 |
| 🔴 上級 | 150問 | 10社×10ステップ＝100問 | 250問 |

全10フレームワーク×100問ずつの完全バランス設計。

### Gemini追加作成問題（ユーザー生成）

- Gemini API（2.5 Pro / 3.1 Pro Preview）で新問題を自動生成
- 10カテゴリ×10業種＝100業種から選択
- 10項目の構造チェック＋AIレビューの品質管理
- Claude問題とは分離管理（タブ切替）

## フレームワーク体系（10種×100問）

**■ マーケティングフレームワーク（7種）**

PESTLE分析 → 5フォース分析 → SWOT分析 → クロスSWOT分析 → アンゾフの成長マトリクス → STP分析 → 4P/4C分析

**■ グロースモデル（3種）**

グロースモデル選択 → KPI設計 → 実行戦略パターン

## 難易度設計

| | 初級 | 中級 | 上級 |
|---|---|---|---|
| 正解の見え方 | 明らかに1つ | 2つで迷う | 全部もっともらしい |
| 状況文の読み方 | そのまま読める | 1-2個の条件を拾う | 計算・推論が必要 |
| 不正解の質 | 惜しいが筋が悪い | 別文脈なら正解 | 構造的な罠を含む |

## 品質基準

- 全選択肢を同じ詳細度で記述（正答だけが長い問題はゼロ）
- 選択肢にフレームワーク用語（SO/WO/Product/PLG等）を書かない
- フレームワークの適用は学習者自身が行う設計
- 正答ポジション（A/B/C/D）は各25%の均等分布
- descriptionは回答後にのみ表示（チート防止）
- 数値の整合性（売上・従業員数・利益率が矛盾しない）
- FW別の正しい分析アプローチ（PESTLE=外部要因、SWOT=戦略策定等）

## 機能

### 📝 個別問題モード
- Claude / Gemini問題のタブ切替
- フレームワーク別フィルター（10種）
- 難易度別フィルター（初級/中級/上級）
- 「未回答のみ」出題フィルター
- 出題数スライダー
- ランダム出題

### 📋 総合ケースモード
- 35社から企業を選択
- PESTLE→5F→SWOT→…→実行戦略の順に10問出題
- 1社の戦略を一貫ストーリーで追体験

### 💬 壁打ちモード（Gemini API連携）
- 問題の解説後に「壁打ちする」でAIと戦略議論
- モデル選択：⚡ 2.5 Flash / 💎 2.5 Pro / ◆ 3.1 Pro Preview
- ターン数選択：3 or 5
- コスト追跡：1ターン概算 + 今月累計
- 503エラー時のターン消費回避（自動リトライ）

### ✏️ 問題作成モード（Gemini API）
- 10カテゴリ×10業種＝100業種からリスト選択
- 企業規模・経営状況・FW・難易度をプルダウン選択
- 生成モデル選択：◆ 3.1 Pro / 💎 2.5 Pro
- 品質チェック（10項目の構造チェック、全てエラー扱い）
- AI品質レビュー（5項目評価＋改善提案）
- 503時3回リトライ（5秒間隔、モデル固定）
- 追加した問題の個別削除

### 📊 ダッシュボード
- SVGレーダーチャート（FW別正答率）
- 難易度別正答率
- FW別プログレスバー

### 📦 データ管理
- 問題データJSONダウンロード
- JSONファイルインポート＋バリデーション
- 回答履歴エクスポート/インポート

### 戦略レビューカード
- 壁打ち終了時にAIが自動生成
- 壁打ち履歴一覧でカードをサムネ表示

### 弱点パーソナライズ
- レビューカードの「思考パターン」を蓄積→傾向分析
- 壁打ちのシステムプロンプトに弱点を自動注入

### デバイス間同期
- **自動同期**（Firebase Realtime Database）
- **手動同期**（base64エクスポート/インポート）

### 📅 学習カレンダー
- 月別カレンダーで日ごとの学習履歴を可視化
- 正答率による色分け表示（🟢70%+/🟡40-69%/🔴~39%）
- 連続学習日数（ストリーク）追跡
- 月間回答数・学習日数の統計

### 🔖 ブックマーク機能
- 回答後に問題をブックマーク保存
- 個別問題でブックマーク済み問題のみ出題

### ❌ 間違えた問題の再出題
- 個別問題で不正解問題のみフィルター出題

### 🌙 ダークモード/ライトモード
- ワンタップでテーマ切替
- 設定はlocalStorageに保存

### PWA
- ホーム画面に追加でネイティブアプリ風に利用
- Service Worker（PWAサポートのみ、キャッシュなし）

## 使い方

### GitHub Pagesでホスト
1. リポジトリをクローン or フォーク
2. Settings → Pages → Source: `main`, `/ (root)`
3. `https://<user>.github.io/<repo>/` でアクセス

### PWAインストール
- **iOS**: Safari → 共有 → ホーム画面に追加
- **Android**: Chrome → メニュー → アプリをインストール
- **PC**: Chrome/Edge → アドレスバーのインストールアイコン

### Firebase同期セットアップ
1. [Firebase Console](https://console.firebase.google.com/) → プロジェクト追加
2. Realtime Database → テストモードで作成
3. URL（`https://xxx.firebaseio.com`）をコピー
4. アプリの設定 → URL＋同期IDを入力

### Gemini APIキー取得
1. [Google AI Studio](https://aistudio.google.com/apikey) → APIキー作成
2. アプリの設定画面 → APIキーを入力
3. 無料枠：3.1 Pro 100回/日、2.5 Pro 100回/日
